# 🏆 Claude Code Tier S — os 12 recursos que mudam seu dia

Curso INEMA.CLUB que ranqueia **todo recurso do Claude de D a S**, com o **Top 12** em contagem regressiva até o #1. O critério não é hype nem popularidade — é **quanto cada recurso muda o seu dia de trabalho de verdade**, pela lente de trabalho de conhecimento e automação.

🔗 **Ao vivo:** https://inematds.github.io/cctop12/

## Estrutura

- **Trilha 1 · A Fundação** (Tier D + C) — o encanamento essencial e as ferramentas de Cowork, voz e web.
- **Trilha 2 · Produtividade Real** (Tier B + A) — workflows paralelos, isolamento, revisão na nuvem e as menções honrosas.
- **Trilha 3 · O Top 12** (Tier S) — a contagem regressiva do #12 ao #1, com o porquê de cada posição.

3 trilhas · 6 módulos · 36 tópicos · ~5h de conteúdo · pt-BR.

## Bônus visual

Em `recursos/` há um **deck futurista navegável** (`tier-list.html`) e **uma imagem PNG de cada slide** (`recursos/imagens/`).

## Como rodar localmente

É um site estático. Abra `index.html` no navegador ou sirva a pasta:

```bash
python3 -m http.server 8080
```
