📉 From #12 to #7

The first half of the Top 12: verifiable goals, cloud planning, usage reports, automatic memory, agent teams, and rewind.

What it is:

Set a goal with a "done" criterion, and Claude won't stop—while verifying—until it meets the condition.

Why learn:

You trigger it, go to sleep or grab lunch, and come back highly confident it’s ready. You don’t need to run it for hours.

Key concepts:

Define "done" as objectively as possible; subjectivity is the Achilles' heel.

What it is:

Offload planning to the cloud with multiple planning agents; review and comment in your browser.

Why learn:

Ideal for large, ambiguous tasks where planning before execution is worthwhile. Keeps working while it plans.

Key concepts:

Runs in the cloud, brings the plan back to the terminal, or executes it directly on the web.

What it is:

Generates an HTML report of your Claude Code usage over the last 30 days: what you did a lot, where you got stuck, and what to use more.

Why learn:

Shows patterns and friction points you don’t notice on your own—quick wins and ambitious workflows to try.

Key concepts:

Check in from time to time to see how your usage evolves.

What it is:

Previously called "autodream": Claude improves its memory on its own, without you asking, at intervals based on sessions/time.

Why learn:

It “dreams,” scans what’s been done, and gets smarter about each repository — without any work from you.

Key concepts:

Check in /memory whether it’s enabled; turn it on if you want.

What it is:

A named team of agents that run in parallel and talk to each other — panels, personas, debate boards.

Why learn:

Great for hearing different perspectives (beginner, CEO…) debate until they agree. Token-intensive.

Key concepts:

Experimental feature: enable it in settings. Invoke it in natural language.

What it is:

Roll back the code and conversation to an earlier checkpoint—you choose the exact point.

Why learn:

When something went wrong, rewinding is better than saying “no, do it this way”—it clears the polluted context.

Key concepts:

Think of it as cached context: rewind preserves quality better than piling on corrections.

👑 The podium: #6 to #1

The home stretch: subagents, /loop, remote control, routines, the status line, and — the number one feature of all — Skills.

What it is:

Background agents that run in parallel, each in its own context window; they report to the main terminal.

Why learn:

They do several things at once without cluttering your context. Unlike Agent Teams, they don’t talk to each other.

Key concepts:

Definable as markdown in .claude/agents, with its own tools and skills.

What it is:

Repeats a prompt at an interval until a condition is met, using the cron tool.

Why learn:

Lightweight recurring reminders and checks. No need for the /loop — you can ask in natural language.

Key concepts:

Tied to the session (close it, and it’s gone) and turns off automatically after ~7 days.

What it is:

Control your local Claude Code session from your phone or the web, synced in real time.

Why learn:

Go for a walk and keep the session alive; what you type echoes on both devices.

Key concepts:

It’s the same session, not a copy. One link or the Claude app (Code tab).

What it is:

Schedules a real agent (not a script) in cron — locally or in the cloud, with your laptop closed.

Why learn:

You get an agent that researches and makes decisions on a schedule, not just API calls.

Key concepts:

/schedule creates; the desktop app manages them in a calendar and list.

What it is:

Scriptable bottom bar: model, effort, and how much of the context window has been used.

Why learn:

The most underrated feature: you know when to hand off, /clear, or /compact.

Key concepts:

/statusline and describe it (even with a screenshot). Combine it with /context and /usage.

What it is:

Markdown recipes that teach Claude workflows. It opens the “recipe” and follows the steps.

Why learn:

The ecosystem’s biggest force multiplier: consistency > repeating prompts. Create your own and pull in other people’s.

Key concepts:

Simple or complex, chainable, shareable—and they work in Code, Chat, and Cowork.
