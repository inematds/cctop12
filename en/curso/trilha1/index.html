🧱 Essential plumbing (Tier D)

The essential foundation that supports everything: memory files, the context cycle, web search, permissions, uploads, and the rest of the plumbing.

What it is:

A file Claude reads in EVERY session to learn about your project, your rules, and the way you work.

Why learn:

Without it, the experience isn't good. It's the "groundwork," the bare minimum—not flashy, but essential.

Key concepts:

Very important to configure well; start simple and refine over time.

What it is:

The trio for managing the conversation: /clear clears, /compact compacts and /resume resumes.

Why learn:

Basic, but useful every day: manages the session's scarcest resource, context.

Key concepts:

Clear starts from scratch; compact summarizes and continues; resume picks up where you left off.

What it is:

Native web search that CITES its sources, plus web fetch that launches a search on the spot from a link.

Why learn:

Basic, but still useful: brings in current information without leaving the terminal, with verifiable references.

Key concepts:

Search scans the web; fetch starts from a URL and retrieves its content.

What it is:

Control over what Claude can do without asking for confirmation — commands, edits, tools.

Why learn:

It’s the foundation of Auto Mode (Tier A): adjusting permissions now unlocks autonomous workflows later.

Key concepts:

Allow/ask/deny by default; start restrictive and allow what you trust.

What it is:

Drop images, PDFs, and documents directly into the conversation; and change how Claude formats its responses.

Why learn:

Brings in visual and document context without copying and pasting; output styles let you tailor the output.

Key concepts:

Uploads = rich input; output styles = output in the format you prefer.

What it is:

A package of small plumbing pieces: Fast Mode, Custom Themes, IDE Extension, Mobile Apps, Code Review, Sandboxed Bash, Headless, Transcript Viewer, History Search, Shell Mode, and Voice Dictation.

Why learn:

Each one is small, but together they make your day more comfortable — shortcuts, visual comfort, and access from anywhere.

Key concepts:

/fast, /theme, Ctrl+O, Ctrl+R, prefix ! e /voice are the shortcuts to memorize.

🗣️ Cowork, voice, and the web (Tier C)

Good but underused features: voice, the Cowork desktop app, connectors, local file access, citations, and the web/collaboration layer.

What it is:

Full spoken conversations with Claude, hands-free; it also transcribes your speech.

Why learn:

Great for brainstorming without a keyboard. External tools like Wispr Flow make it even faster.

Key concepts:

Trigger with /voice; works for both chatting and dictation.

What it is:

Anthropic's agentic desktop app WITHOUT a terminal, built for knowledge work.

Why learn:

A great product, but almost everything it does can be done in Claude Code (with more capabilities).

Key concepts:

A good entry point for nontechnical users who feel overwhelmed.

What it is:

Add and manage MCP connectors INSIDE the CLI — log in to a service and have its tool calls available right away.

Why learn:

Avoids setting up MCP manually in the terminal; it’s interactive and automatic after login.

Key concepts:

Once you log in, the connector's tools appear for Claude to use.

What it is:

Connect a folder for Claude to read and organize your files.

Why learn:

It’s a major benefit of local terminal agents: they work on your actual files.

Key concepts:

Point it to a folder; the agent reads, organizes, and edits its contents.

What it is:

Citations anchors answers in your documents with exact citations (API); Chat Search searches all past conversations.

Why learn:

Citations provides confidence and traceability; Chat Search retrieves what you've discussed before.

Key concepts:

Citations = where the answer came from; Chat Search = where we've discussed it before.

What it is:

The web and collaboration layer: Claude in Slack, Incognito Chats, /teleport, Cowork Plugins, and Cowork Projects.

Why learn:

Brings Claude to where your team already works and gives you privacy when you need it.

Key concepts:

In Slack, mention @Claude; Incognito doesn’t save, remember, or train; /teleport pulls a web session into the terminal.
