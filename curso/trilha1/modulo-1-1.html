📄 CLAUDE.md (Memory Files)

O CLAUDE.md é o arquivo que o Claude lê em toda sessão para conhecer o seu projeto. Não é chamativo, ninguém o elege favorito — mas é o groundwork, o mínimo. Sem ele configurado, a experiência simplesmente não é boa: o Claude começa do zero todo dia, sem saber das suas regras, do seu stack ou do seu jeito de trabalhar.

🧩 O que colocar no arquivo

O CLAUDE.md é texto simples. Ele carrega o contexto que você não quer repetir toda sessão:

  • •Stack, convenções e comandos do projeto (como rodar, como testar).
  • •Regras de estilo e preferências de como você quer que ele trabalhe.
  • •Pode ser global (vale para tudo) ou por projeto (na raiz do repo).

💡 Dica prática

Comece pequeno: três ou quatro linhas já mudam a experiência. Refine conforme você percebe o Claude errando o mesmo ponto — cada correção recorrente é uma candidata a virar uma linha do CLAUDE.md.

♻️ Context Lifecycle

Três comandos para gerenciar a conversa: /clear limpa e começa do zero, /compact compacta o que já foi dito e segue, e /resume retoma uma sessão anterior. Básicos — mas você usa todo dia, porque controlam o recurso mais escasso da sessão: o contexto.

1

/clear — limpar

Esvazia a janela e começa uma conversa nova. Use quando trocar de assunto e não quiser arrastar o contexto antigo.

2

/compact — compactar

Resume o que já aconteceu para liberar espaço e continua a mesma tarefa. Ideal quando a janela está enchendo mas você não terminou.

3

/resume — retomar

Volta para uma sessão anterior e continua de onde parou. Bom para tarefas que se estendem por vários dias.

/clear

Zera a conversa.

/compact

Resume e segue.

/resume

Retoma uma sessão.

Diário

Útil todo dia.

🔎 Web Search & Fetch

O Claude tem busca nativa na web que cita as fontes — então você consegue verificar de onde veio cada informação. E o web fetch dispara uma pesquisa na hora a partir de um link. Básico, mas ainda útil: traz informação atual sem você sair do terminal.

✓ Quando usar

  • ✓Checar um fato recente que pode estar fora do conhecimento do modelo.
  • ✓Buscar e citar fontes em uma resposta que precisa ser verificável.
  • ✓Puxar o conteúdo de uma URL específica que você já tem.

✗ Não confundir

  • ✗Search varre a web; fetch parte de um link específico.
  • ✗Não é busca interna do código — para isso há outras ferramentas.
  • ✗Sem citação não é o mesmo: o diferencial aqui é citar fontes.

💡 Dica prática

Quando pedir algo que depende de informação atual, peça explicitamente para o Claude buscar e citar. Você ganha rastreabilidade e reduz o risco de resposta desatualizada.

🔐 Permissions

Permissions controla o que o Claude pode fazer sem perguntar: quais comandos rodar, quais arquivos editar, quais ferramentas usar. Parece detalhe, mas é a fundação do Auto Mode (Tier A): ajustar bem as permissões agora é o que destrava fluxos autônomos depois.

🛡️ Os três modos

  • •Allow — o Claude faz sem perguntar.
  • •Ask — ele pede confirmação antes de agir.
  • •Deny — bloqueia de vez aquela ação.
Exemplo · settings allow / ask / deny 
allow: comandos de leitura que você confia
ask:   edições de arquivo e comandos que mudam estado
deny:  ações destrutivas que nunca devem rodar sozinhas

💡 Dica prática

Comece restritivo e libere aos poucos o que você confia. Cada permissão que você concede com calma hoje é menos atrito amanhã — e é o caminho natural para o Auto Mode.

📎 File Uploads & Output Styles

Duas peças simples mas que mudam o conforto do dia: soltar arquivos (imagens, PDFs, documentos) direto na conversa para dar contexto rico; e output styles, que mudam como o Claude formata as respostas para o seu gosto.

✓ File Uploads

  • ✓Solte uma imagem para o Claude ver o que você vê.
  • ✓Mande PDFs e docs em vez de copiar e colar trechos.
  • ✓Entrada rica = respostas mais precisas e com contexto.

✓ Output Styles

  • ✓Mude como o Claude formata as respostas.
  • ✓Mais conciso, mais detalhado, mais técnico — do seu jeito.
  • ✓Saída consistente sem repetir a instrução toda vez.

💡 Dica prática

Antes de descrever um erro de tela em três parágrafos, solte o screenshot. E se você sempre pede o mesmo formato de resposta, configure um output style e pare de repetir.

🧰 O resto da base

Um pacote de pequenas peças do encanamento. Nenhuma é estrela sozinha, mas juntas deixam o dia mais confortável — atalhos, conforto visual e acesso de qualquer lugar.

Velocidade & aparência

  • •Fast Mode — Opus com saída mais rápida (/fast).
  • •Custom Themes — /theme: auto, dark, colorblind-friendly e temas próprios.
  • •IDE Extension — Claude Code no VS Code/JetBrains; bom para começar e para copiar/colar sem o wrap esquisito do terminal.
  • •Mobile Apps — iOS e Android.

Atalhos & modos

  • •Code Review — /code-review do git diff.
  • •Sandboxed Bash e Headless Mode.
  • •Transcript Viewer (Ctrl+O) e History Search (Ctrl+R).
  • •Shell Mode (prefixo !) e Voice Dictation (/voice).
Atalhos para memorizar teclado & comandos 
Ctrl+O  transcript viewer
Ctrl+R  history search
!       shell mode (roda comando direto)
/fast   saída mais rápida do Opus
/theme  troca o tema visual
/voice  ditado por voz

💡 Dica prática

Não tente decorar tudo de uma vez. Adote um ou dois por semana — Ctrl+R e o prefixo ! costumam ser os que mais rápido viram hábito.
