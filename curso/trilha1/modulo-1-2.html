TIER C · COWORK, VOZ & WEB

🎙️ Voice Mode

O /voice abre conversas faladas completas com o Claude — mãos livres. Serve tanto para conversar quanto para ditar. Ótimo para brainstorm sem teclado; ferramentas externas tipo Wispr Flow deixam o ditado ainda mais rápido.

💡 Dica prática

Use a voz para a parte de pensar em voz alta — descrever um problema longo é mais rápido falando do que digitando. Para ditado de alta velocidade, vale acoplar uma ferramenta externa como o Wispr Flow.

TIER C · COWORK, VOZ & WEB

🖥️ Cowork

Cowork é o desktop agente SEM terminal da Anthropic, feito para trabalho de conhecimento. É um produto ótimo — mas quase tudo que ele faz dá para fazer no Claude Code, com mais capacidade. O lugar dele é como ponto de entrada para quem é não-técnico e está sobrecarregado.

✓ Quando Cowork brilha

  • ✓Pessoa não-técnica que se assusta com o terminal.
  • ✓Quem está sobrecarregado e quer uma porta de entrada simples.
  • ✓Trabalho de conhecimento sem precisar de tudo do Code.

✗ Onde o Code ganha

  • ✗Quase tudo do Cowork também roda no Claude Code.
  • ✗O Code tem mais capacidade e mais controle.
  • ✗Para uso avançado, o terminal continua sendo o lar.

💡 Dica prática

Se você já está confortável no terminal, comece pelo Code. Reserve o Cowork para apresentar o ecossistema a alguém não-técnico — é a forma mais gentil de mostrar o que um agente faz.

≈ Code

🔌 Interactive Connectors

Adicionar e gerenciar conectores MCP dentro da CLI. Você loga em um serviço e os tool calls ficam disponíveis automaticamente — sem precisar configurar MCP no terminal na mão. É interativo: logou, as ferramentas aparecem.

Adicione o conector na CLI

3

📁 Local File Access

Conectar uma pasta para o Claude ler e organizar os seus arquivos. É um dos grandes benefícios dos agentes locais de terminal: ele não apenas conversa sobre os arquivos — ele atua neles de verdade, lendo, organizando e editando.

🗂️ O que ele faz com a pasta

  • •Lê o conteúdo para entender o que existe ali.
  • •Organiza, renomeia e reestrutura quando você pede.
  • •Edita arquivos no lugar — não é só leitura.

💡 Dica prática

Aponte para uma pasta bagunçada de downloads ou notas e peça uma organização. É a forma mais rápida de sentir por que ter o agente nos seus arquivos locais é tão valioso.

📚 Citations & Chat Search

Dois recursos de ancoragem e recuperação. Citations ancora as respostas nos seus documentos com citações exatas (via API). Chat Search busca em todas as suas conversas passadas — recupera o que você já discutiu antes.

✓ Citations

  • ✓Ancora a resposta nos seus documentos.
  • ✓Mostra a citação exata de onde veio cada trecho.
  • ✓Disponível via API: confiança e rastreabilidade.

✓ Chat Search

  • ✓Busca em todas as conversas passadas.
  • ✓Recupera aquela decisão que você tomou semanas atrás.
  • ✓"Onde foi que a gente já falou disso?" — resolvido.

💡 Dica prática

Pense neles como par: Citations diz de onde a resposta veio; Chat Search diz onde vocês já falaram daquilo. Juntos, transformam histórico e documentos em memória útil.

TIER C · COWORK, VOZ & WEB

💬 Web & colaboração

A camada que leva o Claude para onde o time já está — e dá privacidade quando você precisa: Claude in Slack, Incognito Chats, /teleport, Cowork Plugins e Cowork Projects.

Colaboração

  • •Claude in Slack — mencione @Claude e ele faz a tarefa e responde no canal.
  • •Cowork Plugins — estende o Cowork com capacidades extras.
  • •Cowork Projects — organiza o trabalho por projeto no Cowork.

Privacidade & ponte

  • •Incognito Chats — chat não salvo, não lembrado e não usado em treino.
  • •/teleport — puxa uma sessão web do Claude para dentro do terminal.

💡 Dica prática

Comece algo de leve no celular ou na web e, quando quiser o poder do terminal, use /teleport para trazer a sessão para o Code sem perder o contexto.
